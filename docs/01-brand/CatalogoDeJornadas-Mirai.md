Catálogo de Jornadas — Tenência

Documento vivo.

Este catálogo reúne as principais situações da vida financeira que o Tenência deve apoiar.

As jornadas são independentes da implementação atual e servem como referência para evolução da UX.

Sempre que uma nova situação real for observada durante o uso do produto, ela deverá ser adicionada aqui.

⸻

Como utilizar este documento

Cada jornada deverá responder às seguintes perguntas durante a revisão de UX.

* O usuário consegue descobrir naturalmente onde realizar essa ação?
* A quantidade de passos é adequada?
* Existe algum momento de dúvida?
* O vocabulário utilizado faz sentido para uma família?
* O usuário consegue concluir a tarefa sem entender o modelo interno do sistema?

Evolução contínua

Este documento não representa funcionalidades.

Representa a vida financeira das famílias.

Novas jornadas podem surgir conforme o produto evolui ou novos comportamentos forem observados.

As telas podem mudar.

A arquitetura pode mudar.

O domínio pode evoluir.

As situações vividas pelas famílias permanecem como a principal referência para o design do Tenência.
