## 🔄 Manutenção

### Quando Atualizar
- [ ] Quando decisão estratégica muda
- [ ] Quando filosofia evolui
- [ ] Quando novo aprendizado sobre usuários
- [ ] Quando novo capítulo de história é escrito

### Quando NÃO Atualizar
- ❌ Quando feature nova é lançada (isso não muda filosofia)
- ❌ Quando team cresce (cultura é documentada, adaptação é natural)
- ❌ Quando métrica muda (KPIs não são filosofia)

### Como Atualizar
1. Edit o arquivo (ou arquivo específico do capítulo)
2. Re-consolidar em Mirai.md
3. Commit com mensagem clara ("Capítulo 2: adiciona novo princípio operacional")
4. Notificar team (@channel: "Mirai.md foi atualizado")
