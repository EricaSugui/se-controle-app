# Mirai — Versão 3.0

## Prefácio

---

### Por que este documento existe

Toda marca possui uma origem.

Mas nem toda marca conhece o propósito que a sustenta.

Este documento tenta responder à pergunta que precede todas as outras: **Quem é a Mirai? Por que existe?**

Não é um registro tático de nomes escolhidos ou cores aprovadas. Não é um manual de como falar sobre a marca — isso está no Brand Book.

Não é um guia de como construir o produto — isso é a Product Constitution.

Este é o documento *fundador*. O que preserva a *filosofia* através das mudanças tecnológicas, de mercado e da equipe.

#### O vazio que precisava ser preenchido

Durante dois anos, documentamos:
- **Tenência.md:** Por que mudamos o nome
- **Brand Book:** Como comunicamos  
- **Product Constitution:** Como construímos
- **Visão de Domínio:** Como o negócio funciona
- **Plano de UX:** Para onde vamos

Todos esses documentos respondiam perguntas específicas. Mas havia um vazio maior.

Se você perguntasse a dez pessoas da equipe — desenvolvedores, designers, product, founder — **"Quem é a Mirai?"**, teria dez respostas diferentes.

Um diria: "Um app de finanças para famílias."

Outro: "Uma plataforma de projeção."

Outro: "Um Motor de Cenários com interface."

Outro: "Uma aposta no futuro."

Todas as respostas têm razão. Nenhuma é suficiente.

Esse vazio deixava a marca vulnerável a três riscos:

1. **Desvio estratégico** — times tomando decisões coerentes com *sua interpretação* da marca, mas divergentes entre si
2. **Perda de identidade** — quando crescer, quando mudar, quando expandir — corre o risco de virar "um app de finanças genérico"
3. **Confusão externa** — investidor, usuário, jornalista, parceiro veem o mesmo produto mas entendem coisas diferentes

Este documento *preenche esse vazio*.

#### O que você vai encontrar aqui

Nove capítulos que formam uma defesa coerente de quem a Mirai é:

- **Capítulo 1:** A História — como chegamos até aqui (Se Controle → Tenência → Mirai)
- **Capítulo 2:** A Filosofia — o que cremos, nossa missão, nossa visão
- **Capítulo 3:** A Marca — por que o nome mudou, o que significa, como foi escolhido
- **Capítulo 4:** O Ecossistema — Mirai + Mei + Kata + Motor de Cenários (as peças que formam o todo)
- **Capítulo 5:** A Personalidade — como a Mirai e a Mei pensam, falam, decidem
- **Capítulo 6:** A Empresa — qual categoria queremos criar, como nos diferenciamos
- **Capítulo 7:** A Cultura — como isso influencia decisões de Produto, UX, Design e Engenharia
- **Capítulo 8:** Manifesto — uma carta aberta sobre o futuro que queremos construir

Cada capítulo é relativamente independente. Você pode pular para o que te interessa. Mas lidos em sequência, contam uma história única.

### Como utilizá-lo

Este é um documento *vivo*. Não é congelado no tempo.

Mas é uma bússola que não muda de direção.

#### Para diferentes públicos

**Se você é fundadora, CEO ou estrategista:**  
Leia na sequência (Capítulo 1 até Capítulo 8). Este documento *define* o negócio que você está construindo. É a resposta para investidor, parceiro, ou para si mesma quando a dúvida bate.

**Se você é membro da equipe (em qualquer área):**  
Comece pelo Capítulo 2 (A Filosofia). Depois aprofunde no seu domínio:
- Produto/UX: Capítulos 2, 4, 7
- Design: Capítulos 5, 7
- Engenharia: Capítulos 2, 4, 7
- Inteligência Artificial/Mei: Capítulos 5, 4, 2

**Se você é novo na equipe:**  
Leia Capítulos 1-2 e a seção do Capítulo 7 que corresponde à sua área. Depois aprofunde conforme necessário.

**Se você é usuário, jornalista ou está avaliando investimento:**  
O Capítulo 8 (Manifesto) é o seu ponto de entrada. Se quiser entender mais: Capítulos 1, 2 e 6.

#### Quando usar este documento

**Decisões estratégicas:** "Devemos adicionar a funcionalidade X?" → Capítulo 2 (A Filosofia) terá a resposta.

**Dúvidas de tom/voz:** "Como devemos escrever para o usuário?" → Capítulo 5 (A Personalidade).

**Conflitos de visão:** "Discordamos sobre o rumo." → Capítulo 2 novamente. Regra de ouro está lá.

**Onboarding de novo membro:** "Quem somos nós?" → Capítulos 1 e 2.

**Pitch para investidor:** "Por que essa empresa é diferente?" → Capítulos 2, 6 e 8.

**Redação de conteúdo (marketing, help, microcopy):** "Como deveríamos falar sobre X?" → Capítulo 5 (tom) + Brand Book (como comunicar).

### Relação com os demais documentos

Você não precisa ler tudo para entender a Mirai. Mas eis como cada documento se relaciona:

#### Tenência.md
**Pergunta que responde:** "Por que mudamos o nome de Se Controle para Tenência?"

**Como Mirai.md adiciona:** Tenência foi a parada estratégica. Este documento explica por que *mudamos novamente* — de Tenência para Mirai. Mostra que não é capricho de nome, mas evolução da compreensão sobre o que o produto *é*.

#### Brand Book
**Pergunta que responde:** "Como a marca fala?"

**Como Mirai.md adiciona:** O Brand Book diz *como comunicamos*. Este documento diz *por que comunicamos assim*. Brand Book explica a tática (tons, paleta, voz). Mirai.md explica a estratégia (filosofia que sustenta a tática).

**Analogia:** Brand Book é a gramática. Mirai.md é o livro.

#### Product Constitution
**Pergunta que responde:** "Quais são as leis que guiam o produto?"

**Como Mirai.md adiciona:** A Constituição diz *o que fazer* (princípios operacionais). Mirai.md diz *por que fazer* (propósito que sustenta os princípios).

**Exemplo:**
- Constituição: "A IA nunca substituirá o julgamento humano."
- Mirai.md: "Porque acreditamos que a autonomia do usuário é sagrada. Mirai existe para ampliar compreensão, nunca para criar dependência."

#### Visão de Domínio
**Pergunta que responde:** "Como o negócio funciona hoje? Que entidades existem?"

**Como Mirai.md adiciona:** Visão de Domínio fala de *casas, pessoas, contas, contratos*. Mirai.md fala de *famílias, futuro, autonomia, decisão consciente*. Uma descreve o sistema. Outra descreve o *significado* do sistema.

#### Plano de UX Pós-Motor de Cenários
**Pergunta que responde:** "Qual é a próxima fase de evolução?"

**Como Mirai.md adiciona:** O Plano foca em *como melhorar usabilidade* (discoverable, esforço cognitivo, linguagem natural). Mirai.md situa *por que essas melhorias importam* — porque estamos construindo uma plataforma de decisão, não um sistema de registro.

#### Catálogo de Jornadas
**Pergunta que responde:** "Como as famílias vivem? Que jornadas precisamos apoiar?"

**Como Mirai.md adiciona:** Catálogo mapeia *as jornadas que o usuário vive*. Mirai.md mapeia *a jornada que a marca percorre* — sua evolução, seus valores, seu destino.

### Princípios que guiam este documento

**Autenticidade acima de perfeição.**  
Este documento fala verdadeiro. Não vai ter resposta pronta para tudo. Vai ter tensões, perguntas em aberto, hipóteses que ainda são hipóteses.

**Vivo, não congelado.**  
Quando descobrirmos algo que mude nossa compreensão de quem somos, atualizamos. Mas a direção central — o propósito — não muda.

**Coerência, não uniformidade.**  
Todos na equipe não precisam pensar igual. Mas precisam entender *por que* as decisões vão numa direção.

**Prática, não acadêmico.**  
Este documento foi escrito para ser *usado*. Cada seção responde a uma decisão real que você vai tomar.

---

### Uma nota importante

Se este documento fosse escrito por um conselheiro externo, seria mais polido, mais seguro, mais corporativo.

Mas não seria *verdadeiro*.

Está escrito por quem vive o dia a dia construindo a Mirai. Por isso tem a voz que tem. Por isso aponta incertezas junto com certezas.

Isso é intencional.

A Mirai não nasceu de uma estratégia perfeita. Nasceu de uma pergunta real (como organizar as finanças de uma casa?) que evoluiu para outra pergunta (como ajudar famílias a compreender o próprio futuro?).

Este documento preserva essa trajetória.
