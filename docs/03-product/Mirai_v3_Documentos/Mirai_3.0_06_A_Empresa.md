# Capítulo 6 — A Empresa

## 6.1 A Categoria Que Queremos Criar

Mirai não quer competir em uma categoria existente.

Quer criar uma categoria *nova*.

### A Categoria Atual (Crowded)

**"Apps de Finanças para Famílias"**

Exemplos: Organizze, Mobills, GuiaBolso, etc.

Características:
- Foco em registro histórico
- Controle de orçamento
- Recomendações genéricas
- Monetização por publicidade ou upsell

Mercado:
- Saturado
- Competição em features
- Difícil diferenciação
- Commoditizado

### A Categoria Nova (que Mirai está criando)

**"Plataforma de Apoio à Decisão Familiar"**

Características:
- Foco em compreensão do futuro
- Motor de Cenários como core
- Sem recomendações genéricas (cenários, não regras)
- Monetização por valor real entregue (não publicidade)

Mercado:
- Inexistente (portanto, defensável)
- Competição em verdade de dados e precisão
- Fácil diferenciação (ninguém mais faz)
- Posicionado como premium/inteligência

### Por Que Criar Uma Categoria Nova

Se Mirai competisse em "apps de finanças", teria que:
1. Ter mais features
2. Ser mais barato
3. Oferecer recomendações melhores
4. Fazer interface mais bonita

Campos onde concorrentes já são bons.

Mirai cria uma categoria onde *ninguém* é bom: **apoio à decisão prospectiva**.

Aí, Mirai não compete. Mirai *domina*.

## 6.2 Diferenciação

### Eixo 1: Tecnologia

#### Motor de Cenários
Nenhum concorrente tem projeção de verdade.

GuiaBolso tem "simulador" (entrada de dados + regras).

Mirai tem Motor (dados históricos + lógica + cenários ilimitados).

**Defensibilidade:** Alto (requer arquitetura específica; não é feature que se copia em 3 meses)

#### Dois Eixos Obrigatórios
Competência e Caixa sempre visíveis.

Todos os concorrentes mostram apenas uma (usualmente Caixa).

Mirai mostra que a mesma pergunta tem duas respostas legítimas.

**Defensibilidade:** Médio (é conceitual; pode ser copiado, mas exige redesign total)

#### Contrato com História
Reajustes criam versões. "Quando mudou e por quê?"

Concorrentes tratam como "edição de contrato" (histórico se perde).

**Defensibilidade:** Médio-Baixo (é implementação específica; pode ser copiado)

### Eixo 2: Posicionamento

#### Posição Emocional
Mirai posiciona como "clareza para decisões", não "vigilância".

Concorrentes posicionam como "controle de gastos".

**Diferencial:** Emocional, não técnico. Mais defensível porque está em mentes, não em code.

#### Abordagem de IA
Mirai usa IA para *explicar*, não para *decidir*.

Concorrentes (crescentemente) usam IA para *recomendar*.

**Diferencial:** Filosófico. Mirai apela para autonomia; concorrentes para conveniência.

#### Sem Publicidade
Mirai nunca venderá dados ou espaço de publicidade.

Concorrentes dependem de publicidade como receita secundária.

**Diferencial:** Modelo de negócio. Confiança é vantagem.

### Eixo 3: Comunidade

#### Família Como Unidade
Mirai não é "sua conta" — é "a conta da casa".

Concorrentes são individuais + funcionalidade de compartilhamento fraca.

**Diferencial:** Arquitetura (casa é raiz da árvore, não pessoa)

#### Visibilidade Compartilhada
Todos na casa veem os mesmos dados, os mesmos cenários.

Concorrentes fragmentam (cada pessoa tem sua visão).

**Diferencial:** Experiência (coesão familiar aumenta valor)

## 6.3 Concorrentes Diretos

Não existem *concorrentes diretos* porque não existe categoria direta.

Mas existem concorrentes *indiretos* em diferentes aspectos:

### Registro / Organização
- **Organizze** — histórico, categorização, relatórios
- **Mobills** — mobile-first, interface moderna
- **GuiaBolso** — agregação de contas, análise

### Projeção / Planejamento
- **Planilhas Excel/Google** — total customização, sem UX
- **Ferramentas empresariais** — muito complexas, caras
- **Consultores financeiros** — manuais, caros, não escalável

### IA / Assistência
- **ChatGPT** — genérico, não integrado com dados
- **Wealthfront / Betterment** — IA para investimentos (não cashflow familiar)

Mirai está em um ponto *entre* esses mundos:
- Melhor que planilhas (UX, automação)
- Mais simples que ferramentas empresariais (não precisa ser acionista de empresa)
- Mais honesto que consultores (sem conflito de interesse)
- Mais específico que ChatGPT (integrado com dados reais)

## 6.4 Vantagem Competitiva: 10 Anos Defensabilidade

Se Mirai executar bem, temos vantagens defensáveis por pelo menos 10 anos:

### Year 1-2: Tecnologia
Motor de Cenários é o moat.

Requer pesquisa em projeção, testes com usuários, iteração.

Concorrentes ainda estão descobrindo que Motor existe.

### Year 3-4: Comunidade
Rede de famílias é o moat.

Quanto mais dados históricos, melhor a projeção.

Quanto mais famílias, mais padrões aprendemos.

Concorrentes chegam atrasados.

### Year 5-7: Confiança
Reputação é o moat.

"Mirai é onde as famílias confiam para decisões importantes."

Isso não se copia.

### Year 8-10: Expansão
Outros domínios (saúde, educação, patrimônio) sob mesma marca.

Famílias começam a usar Mirai para *todas* as decisões.

Stickiness muito alta.

Concorrentes ainda estão em "controle de gastos".

## 6.5 Expansão: O Roadmap Global

### Fase 1 (Hoje): Brasil
- Português-BR
- Considerações de imposto (IRPF, Imposto de Renda)
- Integração com sistema bancário brasileiro

### Fase 2: América Latina
- Português-PT + Espanhol
- Estruturas fiscais diferentes
- Nomes de moedas, instituições

### Fase 3: Global
- Inglês
- Estruturas familiares diferentes (EUA vs. Índia vs. Japão)
- Sistemas de saúde / educação / previdência completamente diferentes

### Desafio de Expansão

Mirai não é um produto "um tamanho serve para todos".

Cada região tem:
- Impostos diferentes
- Estruturas de família diferentes
- Conceitos de patrimônio diferentes
- Formas de decisão diferentes

Solução:
- **Core (Motor):** Universal
- **Interface/Linguagem:** Localizada
- **Conceitos:** Adaptados

## 6.6 Modelo de Negócio (Rascunho)

### Opção A: Subscription (SaaS)
- R$ 9,90/mês por casa
- Básico: acesso + 12 meses de histórico
- Premium: acesso + histórico ilimitado + Mei avançada

**Vantagem:** Previsível, alinha com valor (menos culpa)  
**Desvantagem:** Churn se não entregar valor consistente

### Opção B: Freemium + Premium
- Grátis: registro + dashboard básico (2 meses histórico)
- Premium: cenários + histórico ilimitado (R$ 9,90/mês)

**Vantagem:** Bait na porta; simples conversão  
**Desvantagem:** Motor é complexo; muitos usarão grátis

### Opção C: Pontos Críticos
- Grátis: tudo até 12 meses de histórico
- Premium: motor avançado + Mei dedicada (R$ 19,90/mês)

**Vantagem:** Motor é diferencial real; Premium é fácil justificação  
**Desvantagem:** Precisa entregar Motor de verdade

**Decisão Atual:** Explorar Opção C

## 6.7 Visão de Empresa (Longo Prazo)

### Tamanho da Oportunidade

Famílias precisam tomar decisões.

Todas as decisões importantes têm componente financeiro.

Se Mirai conseguir "ser a plataforma de decisões da família", o mercado é:

**Brasil:** 30 milhões de famílias × (1% adoção) = 300k usuários ativos  
**Mundo:** ~2 bilhões de famílias × (1% adoção) = 20M usuários ativos

A 1% de adoção, uma empresa muito grande.

## 6.8 Reflexão: Empresa com Propósito

Mirai não é empresa que quer "ser grande".

Quer "resolver um problema importante".

Se resolver bem, fica grande como consequência.

Mas a métrica de sucesso não é tamanho.

É impacto: quantas famílias conseguiram tomar decisões melhores porque usaram Mirai?
